# Посібник з індексування

## Огляд

semidex — це локальна семантична система індексування та пошуку для AI-агентів. Вона розбиває документи на частини, генерує контекст і теги за допомогою Ollama, вбудовує текст через ONNX-модель та зберігає результати у Qdrant для гібридного пошуку.

## Налаштування

Для роботи потрібні:
- Qdrant (хмарний або локальний через Docker)
- Ollama з моделями `gemma3:4b` і `bge-m3`
- Node.js версії 18 або вище

Змінні середовища задаються у файлі `.env`:

```
QDRANT_URL=https://your-instance.qdrant.io
QDRANT_KEY=your-api-key
CONTEXT_MODEL=gemma3:4b
TAG_MODEL=gemma3:4b
ONNX_EMBED=1
```

## Режим COMBINED_LLM

Якщо встановити `COMBINED_LLM=1`, індексатор виконує один LLM-виклик на чанк замість двох. Це зменшує затримку приблизно на 25-30% на моделі `gemma3:4b`. Змінна `TAG_MODEL` при цьому ігнорується — використовується тільки `CONTEXT_MODEL`.

У разі помилки парсингу JSON-відповіді, індексатор автоматично переходить до окремих викликів для контексту і тегів — знову ж таки через `CONTEXT_MODEL`. Індексування ніколи не зупиняється через помилку парсингу.

## Пошук

```bash
# Через MCP-сервер
qdrant_search("як налаштувати ONNX", "my-docs")

# Або безпосередньо через npm
npm run bench:retrieval
```
