# Collection Snapshot Lifecycle

## Snapshot Rotation Policy

Кожна колекція Qdrant отримує автоматичний знімок раз на добу; застарілі
знімки старші за SNAPSHOT_RETENTION_DAYS видаляються під час нічного
обслуговування. Це не залежить від активності запитів чи стану кешу
векторів.

## Cold Start Warm-Up Interplay

Під час холодного старту індексатор інколи запускається одночасно з
прогрівом кешу векторів іншого сервісу — у такому випадку рекомендується
розвести їх у часі, щоб уникнути конкуренції за дисковий I/O.

## Backup Verification Checklist

- [ ] знімок створено успішно
- [ ] контрольна сума збігається з попереднім знімком
- [ ] розмір знімка в межах очікуваного діапазону
