# Demo-колекція: ТОВ «Добра Крамниця»

> **Це повністю синтетична demo-колекція.** Компанія, документи, ідентифікатори
> та правила вигадані для демонстрації semidex (відео Web3 Resilience Lab).
> Тут немає реальних даних, персональної інформації, контактів чи адрес.

## Про компанію

**ТОВ «Добра Крамниця»** — умовний онлайн-магазин товарів для дому. Колекція
показує, як semidex перетворює внутрішні документи малого та середнього бізнесу
на пошукову базу знань, до якої AI-асистент звертається через MCP.

На цьому прикладі видно типові переваги для бізнесу:

- оператор підтримки швидко знаходить точне правило, а не перечитує регламенти;
- природномовний запит повертає потрібний абзац із посиланням на джерело;
- точні внутрішні ідентифікатори (`REFUND-ESCALATION`, `DELIVERY-DELAY`)
  знаходяться як є;
- система розрізняє актуальний і застарілий контент.

## Індексація

Індексується лише підкаталог `docs/` — README до колекції не потрапляє.

```powershell
$env:COLLECTION="web3lab-demo-company-v2"
$env:ONNX_EMBED="1"
npm run index .\examples\demo-company\docs
```

`ONNX_EMBED=1` дає кращу багатомовну якість для української мови та точний
пошук технічних токенів.

## Рекомендовані demo-запити

Усі запити нижче перевірені без `source_file`-фільтра — контентний документ
виходить у топ нефільтровано.

### 1. Основний запит природною мовою

```text
Яка процедура повернення коштів у нестандартному випадку, хто її погоджує і скільки часу займає відповідь?
```

**Очікуване джерело:** `docs/returns-and-refunds.md`, секція «Нестандартне повернення».
**Очікувана відповідь:** погоджує старший менеджер підтримки; строк відповіді —
до 2 робочих днів.

Для відео після пошуку покажіть ширший контекст:

```text
qdrant_get_chunk(collection="web3lab-demo-company-v2", source_file="returns-and-refunds.md", chunk_index=<знайдений>, window=1)
```

### 2. Exact-token пошук

```text
REFUND-ESCALATION
```

**Очікуване джерело:** `docs/returns-and-refunds.md`. Показує, що точний внутрішній
ідентифікатор знаходиться як лексичний токен.

### 3. Додатковий бізнес-запит

```text
Коли затримку доставки потрібно передати на ескалацію?
```

**Очікуване джерело:** `docs/delivery.md`, секція «Ескалація затримки».
**Очікувана відповідь:** після 3 робочих днів затримки понад стандартний строк.

### 4. Distractor-перевірка

```text
Який тариф використовувати для нового бізнес-клієнта?
```

**Очікуване джерело:** актуальний `PLAN-BUSINESS` у `docs/product-plans.md`, **а не**
застарілий `PLAN-BUSINESS-ARCHIVE`. Демонструє, що semidex розрізняє актуальний
і застарілий контент.

## Provenance у відео

Кожен результат пошуку повертає:

- `source_file` — з якого документа взято чанк;
- `section` — заголовок секції;
- `chunk_index` — позицію чанка для повторюваного доступу.

Це дозволяє показати у відео, що відповідь спирається на конкретне джерело, а
не «вигадана» моделлю.
