# Тарифні плани обслуговування

Документ описує умовні тарифні плани співпраці ТОВ «Добра Крамниця» з
клієнтами та бізнес-партнерами. Усі назви та умови вигадані для
демонстрації.

## Доступні тарифи

### Старт

Базовий тариф для приватних клієнтів. Підходить для разових та нечастих
покупок без додаткових умов.

### Плюс

Тариф для активних клієнтів: накопичувальні знижки та пріоритетна
підтримка на рівні L1.

### Бізнес

Тариф для бізнес-клієнтів і регулярних оптових замовлень.

Ідентифікатор тарифу: **PLAN-BUSINESS**.

Базові умови:

- персональний менеджер;
- відтермінування оплати за погодженням;
- пріоритетна обробка замовлень;
- розширені умови повернення для оптових партій.

**Це єдиний актуальний тариф для нових бізнес-клієнтів.** Усі нові бізнес-клієнти
підключаються до PLAN-BUSINESS. Будь-яке оформлення за іншим бізнес-тарифом для
нового клієнта є помилкою.

## Застарілий архівний тариф

**PLAN-BUSINESS-ARCHIVE** — архівний тариф, виведений з активного обслуговування.

Залишений у документації виключно для обробки договорів, укладених до 2024 року.
Умови архіву не відповідають поточним правилам і не застосовуються при укладенні
нових договорів.

|-------|---------------|----------|-----------|--------|
| Старт | PLAN-START | Приватні клієнти | L1 | Активний |
