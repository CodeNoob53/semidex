# Доставка замовлень

Документ описує доступні канали доставки, строки та порядок дій у разі
затримки для ТОВ «Добра Крамниця».

## Стандартні строки доставки

- Кур'єрська доставка по місту — 1–2 робочі дні.
- Доставка у відділення перевізника по Україні — 2–4 робочі дні.
- Адресна доставка по Україні — 3–5 робочих днів.

Строк відлічується з моменту підтвердження замовлення та надходження
оплати (для передплати) або з моменту оформлення (для післяплати).

## Самовивіз

Клієнт може забрати замовлення самостійно з пункту видачі:

- замовлення зберігається **3 робочі дні** після повідомлення про
  готовність;
- для отримання потрібен номер замовлення;
- неотримане у строк замовлення повертається в обробку.

## Затримка доставки

Затримкою вважається перевищення верхньої межі стандартного строку для
обраного каналу доставки. Поширені причини: відсутність товару на складі,
збій у перевізника, помилкові дані отримувача.

Ідентифікатор процесу: **DELIVERY-DELAY**.

Порядок дій оператора:

1. Зафіксувати звернення про затримку.
2. Перевірити статус відправлення у перевізника.
3. Поінформувати клієнта про очікувану нову дату.
4. Запропонувати рішення: очікування, заміна каналу або скасування.

## Ескалація затримки

Якщо затримка перевищує **3 робочі дні** понад стандартний строк, звернення
передається на ескалацію керівнику логістики.

Правила ескалації:

- ескалація обов'язкова після 3 робочих днів затримки;
- клієнт отримує персональне рішення (компенсація доставки або
  пріоритетна повторна відправка);
- оператор не закриває звернення до підтвердження рішення керівником
  логістики.

## Канали доставки

| Канал | Строк | Вартість | Примітка |
|-------|-------|----------|----------|
| Кур'єр по місту | 1–2 дні | Фіксована | Доступно у великих містах |
| Відділення перевізника | 2–4 дні | За тарифом перевізника | Найпопулярніший канал |
| Адресна доставка | 3–5 днів | За тарифом перевізника | До дверей отримувача |
| Самовивіз | У день готовності | Безкоштовно | Зберігання 3 робочі дні |
